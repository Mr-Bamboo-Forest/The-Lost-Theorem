Behind the scenes of building The Lost Theorem
v0.8: Settings Overhaul, Bug Fixes, and AdSense Prep

The biggest quality-of-life update so far. Here is what changed in v0.8.

Settings Panel. The three separate top-right buttons (World Map, Inventory, Fullscreen) are gone. In their place is a single cog icon that opens a settings panel. From there you can navigate to the World Map or Inventory, toggle fullscreen or exit it, adjust the volume slider, toggle the blocked tile glow effect, show the joystick on mobile, read the How to Play guide, and reset all progress.

Bug fixes. Several critical bugs were fixed in this update:

  • Returning to the title screen and pressing Begin Journey no longer spawns the player into a broken, non-responsive world. The root cause was a stale Object.defineProperty patch on gs.screen that left pointer events blocked on invisible overlay elements. This has been rewritten to use explicit syncJoyVisibility() calls at every screen transition point.
  • Resetting progress or cycling fullscreen rapidly no longer freezes the page. The fix involved removing pointer-events:all from elements that are display:none, ensuring invisible overlays can never swallow input.
  • The joystick toggle has been moved from a standalone bottom-bar button into the settings panel, simplifying the HUD significantly.

Music system. Placeholder file paths have been added for per-world and per-screen audio tracks. When audio files are placed in the /audio/ folder they will load and loop automatically, with world-specific tracks switching on map entry.

Site pages. This dev blog, a Lore page, About, Privacy Policy, and Terms of Service have been added to the site to prepare for Google AdSense review.

v0.7: Joystick, Movement Fixes, and Blocked Tile Glow

v0.7 focused on mobile playability and movement feel.

Virtual joystick. A touch-based virtual joystick now appears automatically on mobile devices. It supports both touch and mouse input, with a dead zone and clamped travel distance. The joystick can be toggled on or off via the settings panel.

Movement behaviour. The movement system was changed so that a single keypress moves exactly one tile immediately, with the held-repeat timer reset on each fresh press. This means tapping moves one step, holding moves continuously, and releasing stops movement cleanly. Previously, the hold-repeat could compound with fresh presses to produce erratic multi-step jumps.

Blocked tile glow. Impassable tiles (water, mountains, trees, ruin walls) now have a subtle amber outline to indicate they cannot be traversed. This is off by default and can be toggled in the settings panel under Display.

In-app browser redirect. The game now detects when it is being opened inside Instagram, TikTok, Facebook, or other in-app browsers and redirects users to their real browser, where the game runs correctly.

v0.6: Statistical Archipelago and The Combinatorial Archives

Two more worlds shipped in v0.6, bringing the total to ten and completing the main content of the game.

The Statistical Archipelago covers statistics: mean, median, standard deviation, interquartile range, hypothesis testing, regression, confidence intervals, and outlier detection. The world has five NPCs: the Data Collector, the Hypothesis Judge, the Regression Keeper, the Confidence Sage, and the Outlier Watcher.

The Combinatorial Archives covers combinatorics: permutations, combinations, stars and bars, and derangements. Its NPCs are the Arrangement Sage, the Selection Scholar, the Stars and Bars Keeper, and the Derangement Master.

With all ten worlds in place, the focus has shifted to polish, bug fixing, and accessibility. The world map was redesigned to show completion state clearly, with completed worlds highlighted in green.

v0.5: The Null Space, Inventory, and World Completion

v0.5 added The Null Space, the game's most abstract world, dedicated to complex numbers. Its six NPCs cover complex arithmetic, modulus and argument, De Moivre's theorem, roots of unity, division using conjugates, and locus problems.

The Inventory system was added in this update. Players can now view all collected Artefacts across all worlds in a 60-slot grid. Each Artefact shows its icon, name, and source world. The Inventory is accessible via the E key, a mobile button, or the settings panel.

World completion tracking was also added. Completing all NPCs in a world turns its card green on the world map. The HUD artefact counter updates in real time.

Progress is now persisted across sessions using localStorage. Artefacts and NPC cooldowns survive browser refreshes. A Reset Progress option allows players to start over if needed.

v0.4: Six Worlds, NPC Dialogue, and the Problem System

v0.4 was the first version that felt like a complete game. Six worlds were in place, each with a full set of NPCs, dialogue, and curriculum-aligned maths problems.

The dialogue system shows NPC name, location, and flavour text, then cycles through two or three lines of character-specific dialogue before presenting the problem screen. Each NPC has three questions in their pool, with one chosen randomly on world load, so repeat visits feel different.

The problem system gives players three attempts per NPC. A correct answer earns an Artefact and sets a cooldown on that NPC. Incorrect attempts show feedback immediately. After all three attempts are spent, the player is returned to the map and the NPC enters a longer cooldown.

Worlds added in v0.4: Algebra Aces (polynomials, logarithms, sequences, induction, domain and range), The Vector Wastelands (dot product, cross product, lines and planes), and Exponential Depths (exponential growth and decay, logarithmic equations).

v0.3: Tile Engine, Palette System, and the First Three Worlds

The core tile engine was completed in v0.3. All ten worlds share the same 50x38 tile map structure, procedurally generated from a deterministic noise function seeded by the world ID. The map includes a central river, mountain corners, path networks, six ruin sites, and scattered tree clusters. What changes between worlds is the palette: each world has its own set of colour values for grass, dirt, water, paths, ruins, trees, mountains, and NPCs.

This palette system means that adding a new world requires writing only the world data object (ID, name, theme, icon, palette, start position, and NPC array) without touching the map generator or rendering code.

The first three worlds shipped in v0.3: The Integral Plains (calculus), Euclid Bay (geometry), and Probability Hollow (probability). Each had three to six NPCs with handwritten dialogue and a pool of three questions each.

Origins: From a Single File to a Working Prototype

The Lost Theorem started as a question: can a meaningful maths game fit in a single HTML file? No build tools, no frameworks, no server. Just one file you can open in a browser.

v0.1 was a proof of concept: a canvas renderer, a player character, keyboard input, and a single tile map hard-coded as a 2D array. The player could walk around. That was it.

v0.2 added the NPC proximity system, dialogue boxes, and the first working problem screen. The question pool was a single array of five integration questions. The reward system was not yet implemented. But the loop worked: walk, find NPC, talk, answer, return.

From that loop, everything else followed. The decision to build ten worlds came from mapping out the Queensland senior mathematics curriculum and realising that each major topic had enough depth to sustain its own set of characters and environments.
